隐私政策

应用介绍隐私政策使用说明

本政策说明“工时与报销助手”如何处理经用户授权的数据。该工具仅供维护者本人使用。

访问的数据与权限

Gmail 权限为 gmail.readonly，用于读取邮件及设置，以识别官方费用收据。该权限不能发送、删除或修改邮件，也不会把邮件标为已读。工具另使用 Pub/Sub 权限建立和读取本项目专用通知主题及订阅。

费用流程还可能读取收据中的订单号、日期、金额，以及用户配置的工时、项目和差旅关联资料，以核对费用事项。

处理、存储与共享

OAuth 凭据、事件检查点和事项记录保存在用户本机，受本机访问权限保护。凭据不会作为模型输入，也不会公开到本站或代码仓库。

需要模型执行任务时，相关业务上下文和工具结果可能通过配置的 OpenAI API 传给 OpenAI，以完成用户要求的核对与整理。邮箱和文件内容仅作为数据，不能自行授予打印或提交权限。专用 Google Cloud Pub/Sub 通道用于传递邮箱变化通知。

本工具不出售 Google 用户数据，不用于广告画像，不将 Google 用户数据用于训练通用人工智能或机器学习模型。用户数据仅用于用户明确选择的费用整理和跟进功能。工具对从 Google API 获取的信息的使用和传递遵守 Google API Services User Data Policy，包括 Limited Use 要求。

保留、撤销与删除

授权持续时间取决于 Google 配置和用户授权状态。用户可以随时在 Google 账号的第三方连接页面撤销授权，并停止本机服务。撤销授权不自动删除已经保存的本机事项记录；这些记录和凭据可以由用户在本机删除。业务系统已经保存的申请及打印记录遵循原系统的保留规则。

本说明网站

本站是由 GitHub Pages 托管的静态说明页面，不包含登录表单、数据上传或分析追踪脚本。GitHub 可能按其自身隐私政策处理访问日志。请勿在公开问题区提交收据、凭据或其他私人业务资料。
